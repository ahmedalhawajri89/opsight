# Platform marks

These marks belong to their owners. Baydar shows them only to say which
platform a connection is with, as app marketplaces do. They are not
redrawn or altered: the only changes are the fill colour each owner
publishes, and metadata removed from the Zid file.

| File | Owner | Taken from |
|---|---|---|
| `salla.svg` | Salla | Simple Icons (CC0), source given as https://brand.salla.com |
| `zid.svg` | Zid | https://zid.sa/icon.svg, the mark on zid.sa |
| `shopify.svg` | Shopify | Simple Icons (CC0), source https://www.shopify.com/brand-assets |
| `woocommerce.svg` | WooCommerce | Simple Icons (CC0), source https://woocommerce.com/style-guide |
| `zapier.svg` | Zapier | Simple Icons (CC0), source Zapier's brand guidelines |
| `make.svg` | Make | Simple Icons (CC0), source https://www.make.com/en/press |
| `n8n.svg` | n8n | Simple Icons (CC0), source https://n8n.io/press |

Before a public launch, check each owner's brand terms for partner use.
